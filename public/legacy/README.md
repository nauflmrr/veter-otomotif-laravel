# Website Dealer Mobil – PT Veter Otomotif (PHP + MySQL)
1. Letakkan folder di server (XAMPP/Laragon: htdocs / www), pastikan PHP 8+ dan MySQL aktif.
2. Edit config.php (user/password MySQL).
3. Buka http://localhost/veter-otomotif/install.php lalu HAPUS install.php.
4. Admin: admin@veter.test / admin123 (ganti segera). Pelanggan mendaftar lewat register.php.
Modul: Satu Dealer (beranda), Admin Dealer, My Dealer, My Garage, Servis & Suku Cadang. Jika sudah memasang versi 1, hapus database veter_otomotif lalu jalankan install.php lagi.
